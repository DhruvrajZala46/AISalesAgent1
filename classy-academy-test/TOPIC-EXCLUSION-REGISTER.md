# Topic exclusion register (built 22 Oct 2026)

**Read this before recommending any topic.** A new topic must pass three checks against every cluster below:
A. a different title; B. a different audience problem (desire, curiosity or transformation); C. different teaching
content. New wording, a new number of points, a season, a country, an age group, a celebrity or a thumbnail does not
make an old concept new.
