# The Classy Elegance: YouTube production repo

For anything about making a video for the channel, use the skills in `.claude/skills/`:
- `ce-next-video`: the whole pipeline (idea → script → video → package), with approval gates
- `ce-idea`, `ce-script`, `ce-video`, `ce-package`: the individual steps
- `yt-*`: the MIT youtube-agent skill pack these build on (Jake Schincariol)

Channel knowledge lives in `channel/` (voice, measured edit style, storytelling rules, and the
user's feedback in LESSONS.md). Read it first. Text deliverables go in `videos/<slug>/`. Footage and
renders never go in git.
